# Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

## File Descriptions
* **welcome.py**: Contains a function that simplifies repetitive welcome messages into a single reusable block.
* **toolbox.py**: A collection of helper functions handling numerical doubling, score-based pass checks, and customizable greeting strings.

## Reflection
The hardest function to write was `is_pass` because it forces you to think efficiently. Instead of using a traditional `if/else` statement, returning the comparison expression `score >= 50` directly was a new but cleaner way to output a boolean value.
